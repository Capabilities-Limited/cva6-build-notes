# CVA6 September 2025

CapabilitiesLimited has several streams of CVA6-related work which have been tagged with a `cva6-september-2025-` prefix in the [cheri-cva6 repository](https://github.com/Capabilities-Limited/cheri-cva6).


* The main RV64Y CHERI effort is available at tag `cva6-september-2025-boot` (commit `f5680865`)
* The work aiming to make use of the HPDCache for data caches in the CHERI-enabled system is available at tag `cva6-september-2025-hpdcache` (commit `306bdac6`)
* The work aiming to repurpose the HPDCache as a tag cache in the CHERI tag controller component is available at tag `cva6-september-2025-tagctrl` (commit `4d0065be`)
* The work aiming to rebase the RV64Y CHERI effort on a recent version of CVA6 is available at tag `cva6-september-2025-rebase` (commit `6230a010`)


In addition, testing the CHERI CVA6 implementation against the sail CHERI implementation is supported via the [TestRIG repository](https://github.com/Capabilities-Limited/TestRIG) at tag `cva6-september-2025` (commit `9a5d695e`).
